Версия v9: окно на последнем шаге покупки

Путь клиента:
1. Нажать «Купить» в карточке игры.
2. Выбрать сервер (для STANDOFF 2 этот шаг не требуется).
3. Заполнить игровой ник, способ получения и количество валюты либо сумму.
4. Нажать финальную кнопку «Купить».
5. После проверки обязательных полей появится окно о недоступности покупки.

Кнопка окна «Перейти в @PlatinovBot» ведёт на https://t.me/PlatinovBot.
В тексте явно указано, что это другой магазин со своими условиями и ответственностью.
При закрытии окна крестиком, клавишей Esc или нажатием на затемнение данные формы
сохраняются. На предыдущих шагах окно не показывается.
Финальная кнопка не создаёт заказ, не открывает оплату и не отправляет данные в API.

backend/ сохранён из предыдущей версии без изменений: MulenPay отсутствует,
а API заявок pending_manual остаётся в исходниках. Окно в frontend не отключает
серверные API. Это локальная версия; публикация и установка на VDS не выполнялись.
